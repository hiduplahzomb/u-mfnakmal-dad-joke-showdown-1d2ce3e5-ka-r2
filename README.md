# Dad Joke Showdown

A single-line dad joke built around one very specific, very cold number: the thermostat setting that turns an ordinary winter house into a penguin exhibit, with admission paid in blankets and socks.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

This writes the one-line entry to `entry.txt`, verifies it byte-for-byte against the `TEXT` constant, and prints the character count (limit: 200).
